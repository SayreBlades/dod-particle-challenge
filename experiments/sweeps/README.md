# experiments/sweeps/ — sweep configs

One `<layout>.cells` file per layout: the cells to sweep, one per line (`#`
comments allowed). Sourced by `scripts/collect.sh` when no cells are passed on
the command line. The cell manifest (`experiments/cells/<layout>.md`,
generated by `zig build manifests`) is the source of truth for what cells
exist; this file selects the subset worth measuring.

## The regime grid (one pass, §17.5)

Every cell is swept once across:

| axis         | values                  | how it's set                                   |
|--------------|-------------------------|------------------------------------------------|
| **N**        | `4K, 65K, 1M, 16M`      | bench default `SWEEP` (override with `NS=`)   |
| **death q**  | `0.01, 0.05, 0.25`      | `death_rates.txt` (override with `DEATH_RATES=`) |
| **threads**  | `1, 4, 10`              | parallel cells only (override with `THREADS=`)  |

Serial cells run T=1 only (a serial cell ignores `--threads`, so looping it
would just emit duplicate rows). The champion grid is read straight off this
single pass — there is no second "champion pass" anymore.

## Sweep knobs (env vars to `collect.sh`)

| var           | default             | meaning                                          |
|---------------|---------------------|--------------------------------------------------|
| `NS`          | *(bench default)*   | comma-list of N (e.g. `4000,65000,1000000`)      |
| `TRIALS`      | `3`                 | trials per N (min is taken downstream)           |
| `DEATH_RATES` | `0.01 0.05 0.25`    | space-list of accident rates q (competing risks)  |
| `THREADS`     | `1 4 10`            | space-list of worker counts (parallel cells only) |

The bench's built-in N-sweep (when `NS` is unset):
`4000 65000 1000000 16000000`.
